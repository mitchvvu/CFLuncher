# ComfyUI 启动器

## 项目概述

ComfyUI 启动器是一个用于 Windows 平台的工具，可以替代批处理文件启动 ComfyUI。使用 Python 3.10 和 PySide6 开发，提供了图形界面来管理 ComfyUI 的启动选项和设置。

## 主要功能

- **一键启动/停止 ComfyUI**：通过图形界面控制 ComfyUI 的启动和停止
- **代理设置**：配置 HTTP 和 HTTPS 代理，方便在网络受限环境中使用
- **局域网访问**：启用局域网访问，允许其他设备通过网络连接到 ComfyUI
- **低显存模式**：支持低显存模式，适合显存较小的显卡
- **设置持久化**：自动保存和加载用户设置

## 使用说明

### 安装

1. 下载最新的发布版本 `ComfyUI启动器.exe`
2. 将 `ComfyUI启动器.exe` 放置在 ComfyUI 文件夹的同级目录下（与 `python_embeded` 文件夹同级）
3. 双击运行 `ComfyUI启动器.exe`

### 启动 ComfyUI

1. 在「启动」选项卡中，根据需要配置启动选项：
   - 启用代理：如果需要通过代理访问网络
   - 局域网可访问：允许局域网内其他设备访问
   - 低显存模式：如果显卡显存较小
2. 点击「启动 ComfyUI」按钮
3. 启动日志会显示在下方的日志区域

### 配置设置

1. 切换到「设置」选项卡
2. 配置代理设置：
   - HTTP 代理地址
   - HTTPS 代理地址
   - 代理端口
3. 配置局域网设置：
   - 监听地址（默认为 0.0.0.0）
   - 端口号（默认为 8188）
4. 点击「保存设置」按钮保存更改

## 开发指南

### 环境要求

- Python 3.10 或更高版本
- PySide6
- 其他依赖见 `requirements.txt`

### 项目结构

- `main.py`：主程序入口
- `data_model.py`：数据模型，负责配置的存储和读取
- `startup_panel.py`：启动面板，负责 ComfyUI 的启动和停止
- `settings_panel.py`：设置面板，负责配置代理和网络设置
- `about_panel.py`：关于面板，显示应用信息
- `style.qss`：应用程序样式表
- `build.py`：打包脚本

### 打包应用

运行 `build.py` 脚本可以将应用程序打包成独立的可执行文件：

```bash
python build.py
```

打包后的可执行文件将位于 `dist` 目录中。
